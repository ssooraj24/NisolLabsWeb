Interactive Investment Estimator SpecificationUI Component DesignAntigravity should implement an interactive, client-side estimator widget.  Input ControlsIndustry Sector: [ Dropdown: Technology / Finance / Healthcare / Manufacturing / Retail / Services ]  Business Functions to Assess: [ Slider / Dropdown: 1–3 Functions / 4–6 Functions / 7+ Functions ]  Company Headcount: [ Dropdown: 10–50 / 51–250 / 251–1,000 / 1,000+ ]  Operating Locations: [ Dropdown: Single Location / 2–3 Locations / 4+ Locations ]  Engagement Depth: [ Radio: Foundation / Growth / Enterprise ]  Mathematical Calculation ModelThe estimated investment $I_{\text{est}}$ is calculated using the base investment $I_{\text{base}}$ adjusted by operational scope weights:  $$I_{\text{est}} = I_{\text{base}} \times W_{\text{functions}} \times W_{\text{size}} \times W_{\text{locations}} \times W_{\text{depth}}$$Where:Base Investment $I_{\text{base}} = \text{₹}3,50,000$[cite: 1, 5, 6]Function Weight $W_{\text{functions}}$: $1–3 \rightarrow 1.0$, $4–6 \rightarrow 1.4$, $7+ \rightarrow 1.8$  Size Weight $W_{\text{size}}$: $10–50 \rightarrow 1.0$, $51–250 \rightarrow 1.3$, $251–1,000 \rightarrow 1.6$, $1,000+ \rightarrow 2.0$[cite: 1, 5, 6]Location Weight $W_{\text{locations}}$: $\text{Single} \rightarrow 1.0$, $2–3 \rightarrow 1.25$, $4+ \rightarrow 1.5$  Depth Weight $W_{\text{depth}}$: $\text{Foundation} \rightarrow 1.0$, $\text{Growth} \rightarrow 1.5$, $\text{Enterprise} \rightarrow 2.0$  Estimator Display PanelEstimated Investment Range: Displays calculated result as a $\pm 10\%$ range (e.g., ₹6,00,000 – ₹7,50,000).  Estimated Delivery Timeline: Displays 7–11 Business Days or 2–4 Weeks based on selected package[cite: 1, 5, 6].Recommended Package Badge: Automatically highlights the matching card (Foundation / Growth / Enterprise).
