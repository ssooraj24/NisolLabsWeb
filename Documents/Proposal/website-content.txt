# Nisol Labs — Website Pricing Strategy

You are absolutely right. **Do not publish a simple pricing table.** That would commoditize your offering and reduce it to a price comparison, when what you are selling is **strategic AI transformation**.

Instead, position your pricing page as an **Engagements & Investment** page that communicates value first, investment second.

---

## 1. Recommended Page Title

**Option A (Best):**  
> **AI Transformation Engagements**

**Option B:**  
> **Engagements & Investment**

**Option C:**  
> **How We Partner with You**

These titles focus on the **relationship** and **outcome**, not the cost.

### 2.4 Pricing Calculator (Interactive)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  ESTIMATE YOUR AI DISCOVERY ENGAGEMENT                                    │
│                                                                             │
│  Get a personalized estimate for your organization.                        │
│                                                                             │
│  Industry              [Dropdown ▼]                                        │
│  Number of Functions   [Dropdown: 1-3 / 4-6 / 7+]                         │
│  Company Size          [Dropdown: 10-50 / 51-250 / 251-1000 / 1000+]     │
│  Locations             [Dropdown: 1 / 2-3 / 4+]                           │
│  Desired Depth         [Dropdown: Foundation / Growth / Enterprise]       │
│                                                                             │
│  ───────────────────────────────────────────────────────────────────────── │
│                                                                             │
│  📊 Estimated Investment: ₹6,20,000                                        │
│  📅 Estimated Duration: 10 business days                                   │
│  📦 Recommended Package: Growth Engagement                                 │
│                                                                             │
│  [Book Consultation]  [Request Detailed Proposal]                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

**How It Works:**
- The calculator adjusts the estimated price based on client inputs
- It does **not** show a fixed price table—it gives a **range**
- It encourages the client to schedule a call for a precise quote

**Backend Logic (Simplified):**

| Input | Weight |
| :--- | :--- |
| Industry | 1.0x (base) |
| Number of Functions | +0.5x per function beyond 3 |
| Company Size | +0.3x for 51-250, +0.6x for 250-1000, +1.0x for 1000+ |
| Locations | +0.3x for 2-3, +0.5x for 4+ |
| Desired Depth | Foundation: 1.0x, Growth: 1.5x, Enterprise: 2.0x |

**Example Calculation:**

```
Base Price: ₹3,50,000
Industry: Manufacturing (1.0x)
Functions: 5 (1.0x + 0.5x + 0.5x = 2.0x)
Size: 150 employees (1.0x + 0.3x = 1.3x)
Locations: 2 (1.0x + 0.3x = 1.3x)
Depth: Growth (1.5x)

Estimated: ₹3,50,000 × 2.0 × 1.3 × 1.3 × 1.5 = ₹17,74,500
```

**Display:** ₹16,00,000 – ₹20,00,000

## 3. Why This Works

| Strategy | Why It Works |
| :--- | :--- |
| **Value-First Messaging** | Clients focus on what they get, not what they pay |
| **Transparent Starting Prices** | Provides clarity without commoditizing |
| **Tiered Packages** | Creates a natural upgrade path |
| **Comparison Table** | Helps clients understand the differences |
| **Interactive Calculator** | Engages visitors and generates qualified leads |
| **FAQs** | Addresses common objections upfront |
| **No Hourly Rates** | Communicates that this is a strategic engagement, not staff augmentation |
