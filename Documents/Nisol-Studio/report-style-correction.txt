Tweak Margins and Padding to Prevent Overflow
Larger fonts may cause content to spill. Adjust the following:

css
@page {
  size: A4;
  margin: 14mm 16mm;        /* was 12mm 14mm – give more breathing room */
}

Also increase padding on the cover page and sidebar cards:

css
.cover-page {
  padding: 52px;            /* was 48px */
}
.sidebar-card {
  padding: 28px;            /* was 22px */
}
