### 1.2 New Table: `revenue_range_defaults`

**Purpose:** Lookup table for AI and pricing engine to estimate values from revenue ranges.

| Column | Type | Description |
| :--- | :--- | :--- |
| `range_label` | TEXT | Primary key, matches `revenue_range` values |
| `mid_point_cr` | DECIMAL | Mid-point for ROI calculations |
| `min_cr` | DECIMAL | Minimum of the range |
| `max_cr` | DECIMAL | Maximum of the range |

**Seed Data:**
```
< ₹10 Cr → mid_point: 5 Cr
₹10 Cr - ₹50 Cr → mid_point: 30 Cr
₹50 Cr - ₹250 Cr → mid_point: 150 Cr
₹250 Cr - ₹1,000 Cr → mid_point: 625 Cr
₹1,000 Cr - ₹5,000 Cr → mid_point: 3000 Cr
> ₹5,000 Cr → mid_point: 7500 Cr
Prefer not to say → NULL
```

### 1.3 Relationship Between Tables

```
tenants.revenue_range ────► revenue_range_defaults.range_label
       │                               │
       │    (lookup)                    │
       └───────────────────────────────┘

When calculating ROI or benchmarks:
1. Read `tenants.revenue_range`
2. Look up `revenue_range_defaults.mid_point_cr`
3. Use mid-point for financial calculations
```

**Important:** This is a **logical relationship**, not a foreign key constraint. This allows clients to select "Prefer not to say" without breaking calculations.

### 1.4 Computed Column: `company_size`

Derived from `employee_count`:

| Employee Count | Company Size |
| :--- | :--- |
| ≤ 10 | Startup |
| ≤ 50 | Small |
| ≤ 200 | Medium |
| ≤ 500 | Mid-Market |
| ≤ 5000 | Large |
| > 5000 | Enterprise |

**Important:** This is automatically calculated. Do NOT allow manual updates to this field.

## 8. Create Revenue Range Query File

Create `lib/supabase/queries/revenueRangeDefaults.ts`:

```typescript
import { supabase } from '@/lib/supabaseClient';
import { RevenueRangeDefault } from '@/types/database';

export async function getRevenueRangeDefaults(): Promise<RevenueRangeDefault[]> {
  const { data, error } = await supabase
    .from('revenue_range_defaults')
    .select('*')
    .order('min_cr', { ascending: true });

  if (error) throw error;
  return data || [];
}

export async function getRevenueRangeDefault(label: string): Promise<RevenueRangeDefault | null> {
  const { data, error } = await supabase
    .from('revenue_range_defaults')
    .select('*')
    .eq('range_label', label)
    .single();

  if (error) {
    if (error.code === 'PGRST116') return null; // Not found
    throw error;
  }
  return data;
}

export async function getMidPoint(label: string): Promise<number | null> {
  const result = await getRevenueRangeDefault(label);
  return result?.mid_point_cr || null;
}
```
