### INSTRUCTION FOR ANTYGRAVITY: EXECUTIVE CHART REDESIGN (KPMG/McKinsey Style)

The goal is to elevate the visual quality to match Big 4 consulting standards (KPMG, Deloitte, McKinsey) with larger dimensions, premium typography, soft depth, and pristine A4/300DPI output.

#### PART 1: THE UNIFIED SPECIFICATION (Apply to ALL charts)

Please enforce these rules globally across `renderMaturityComparisonSVG`, `renderRadarChartSVG`, `renderHeatmapSVG`, `renderOpportunityMatrixSVG`, and `render5YearROIBarChartSVG`:

1.  **Canvas & Padding**:
    - Base width: `820px`.
    - Height: **Dynamic** (do not hardcode 280px). Calculate with `const height = (padding * 2) + (items.length * 36) + ((items.length - 1) * 56)`.
    - Padding: Strict `40px` on all sides (top, left, right, bottom).
2.  **Bar/Element Sizing**:
    - Bar height: **36px**.
    - Row spacing: **56px** (measured from the start of one bar to the start of the next).
    - Corner radius: **10px** (`rx="10"`) on all bars and container cards.
3.  **Typography (Inter font, strict sizes)**:
    - Chart Title (e.g., "Overall Score"): `18px`, `font-weight="600"` (Semibold).
    - Axis/Line Labels (e.g., "Client Score"): `15px`, `font-weight="500"` (Medium).
    - Numeric Values inside bars (e.g., "$2.4M"): `17px`, `font-weight="700"` (Bold).
    - Score Badges (e.g., "4.2 / 5"): `17px`, `font-weight="800"` (ExtraBold), color `#FFFFFF`.
4.  **Visual Depth (Gradients & Shadows)**:
    - Add a universal `<filter id="shadow">` with `feDropShadow dx="0" dy="4" stdDeviation="4" flood-opacity="0.08"`.
    - Apply `<linearGradient>` to all primary data bars (e.g., from dark base color to a lighter variant of the same hue). *Do not use flat, solid colors for primary elements.*
5.  **Executive Color Palette**:
    - Deep Blue (Primary): `#0A2647` → `#1E3A8A`
    - Emerald (Positive/High): `#059669` → `#10B981`
    - Amber (Warning/Medium): `#D97706` → `#F59E0B`
    - Muted Red (Critical/Low): `#DC2626` → `#EF4444`
    - Background gridlines: `#F1F5F9` with `stroke-dasharray="4 4"`.
6.  **Legends & Headers**:
    - Every chart must include a clear **Legend** in the top-right corner using `<rect>` color keys + `12px` text labels.
    - Include an **"Overall Score"** or specific section header directly above the chart area (inside the SVG).
7.  **Data Formatting**:
    - Convert all raw 0-100 scores to **"X.X / 5"** format (divide by 20). Display this prominently at the end of each bar.

#### PART 2: EXACT CODE REPLACEMENT (Horizontal Bar Chart)

**Action:** Replace the entire `renderMaturityComparisonSVG` function in `pdfComponentEngine.ts` with the code block below. This handles dynamic height and implements *all* of the above specs perfectly.

```typescript
export function renderMaturityComparisonSVG(data: { clientScore: number; industryAvg: number; topQuartile: number }) {
  const items = [
    { label: "Client Score", value: data.clientScore, max: 100, gradient: "gradClient" },
    { label: "Industry Average", value: data.industryAvg, max: 100, gradient: "gradIndustry" },
    { label: "Top Quartile", value: data.topQuartile, max: 100, gradient: "gradTop" },
  ];

  // Dynamic Height Calculation (36px bar + 56px spacing + 40px padding)
  const barHeight = 36;
  const rowSpacing = 56;
  const padding = 40;
  const chartWidth = 820;
  const totalHeight = padding * 2 + (items.length * barHeight) + ((items.length - 1) * rowSpacing);
  
  const labelX = padding;
  const barStartX = 200;
  const maxBarWidth = chartWidth - barStartX - padding;

  const gradients = `
    <defs>
      <filter id="shadow" x="-5%" y="-5%" width="120%" height="120%">
        <feDropShadow dx="0" dy="4" stdDeviation="4" flood-color="#000000" flood-opacity="0.08"/>
      </filter>
      <linearGradient id="gradClient" x1="0%" y1="0%" x2="100%" y2="0%">
        <stop offset="0%" stop-color="#0A2647" /><stop offset="100%" stop-color="#1E3A8A" />
      </linearGradient>
      <linearGradient id="gradIndustry" x1="0%" y1="0%" x2="100%" y2="0%">
        <stop offset="0%" stop-color="#D97706" /><stop offset="100%" stop-color="#F59E0B" />
      </linearGradient>
      <linearGradient id="gradTop" x1="0%" y1="0%" x2="100%" y2="0%">
        <stop offset="0%" stop-color="#059669" /><stop offset="100%" stop-color="#10B981" />
      </linearGradient>
    </defs>
  `;

  let barsHtml = '';
  items.forEach((item, index) => {
    const yPos = padding + (index * (barHeight + rowSpacing));
    const barWidth = (item.value / item.max) * maxBarWidth;
    const textY = yPos + (barHeight / 2) + 6;
    const formattedScore = (item.value / 20).toFixed(1);

    barsHtml += `
      <text x="${labelX}" y="${textY}" font-size="15" font-weight="500" fill="#334155" font-family="Inter, sans-serif">${item.label}</text>
      <line x1="${barStartX}" y1="${yPos + barHeight + 8}" x2="${chartWidth - padding}" y2="${yPos + barHeight + 8}" stroke="#F1F5F9" stroke-width="1" stroke-dasharray="4 4" />
      <rect x="${barStartX}" y="${yPos}" width="${barWidth}" height="${barHeight}" rx="10" fill="url(${item.gradient})" filter="url(#shadow)" opacity="0.95" />
      <text x="${barStartX + barWidth - 12}" y="${textY}" font-size="17" font-weight="800" fill="#FFFFFF" text-anchor="end" font-family="Inter, sans-serif">
        ${formattedScore} / 5
      </text>
    `;
  });

  return `
    <svg viewBox="0 0 ${chartWidth} ${totalHeight}" width="100%" height="auto" preserveAspectRatio="xMidYMid meet" xmlns="http://www.w3.org/2000/svg">
      ${gradients}
      <text x="${padding}" y="${padding - 10}" font-size="18" font-weight="600" fill="#0F172A" font-family="Inter, sans-serif">Overall AI Maturity Score</text>
      <g transform="translate(${chartWidth - 260}, ${padding - 10})">
        <rect x="0" y="0" width="12" height="12" rx="3" fill="#0A2647" /><text x="18" y="11" font-size="12" fill="#64748B" font-weight="500">Client</text>
        <rect x="85" y="0" width="12" height="12" rx="3" fill="#D97706" /><text x="103" y="11" font-size="12" fill="#64748B" font-weight="500">Industry</text>
        <rect x="175" y="0" width="12" height="12" rx="3" fill="#059669" /><text x="193" y="11" font-size="12" fill="#64748B" font-weight="500">Top Quartile</text>
      </g>
      ${barsHtml}
    </svg>
  `;
}
```
