# Nisol AI — Split-Architecture Production Deployment Guide

## Architecture Overview
* **Marketing & Public Site**: Deployed on **Vercel** (`nisolai.com`, `www.nisolai.com`) for global Edge CDN performance, zero cold starts, and asset caching.
* **Core Application & Platform**: Deployed on **AWS EC2 VM** (`app.nisolai.com` at `13.207.146.34`) running Docker Compose:
  - Caddy (Auto-SSL reverse proxy on ports 80/443)
  - Next.js Standalone Portal & API (`nisol-app` on port 3000)
  - PostgreSQL 16 + pgvector (`nisol-postgres` on port 5432)
  - Redis 7 Alpine (`nisol-redis` on port 6379)
  - Ancillary Microservices: TryPost, WAHA, Portainer, Dozzle

---

## Part 1: DNS Setup (At your Domain Registrar / DNS Provider)
Ensure your AWS VM public IP (`13.207.146.34`) is assigned as an **Elastic IP** in AWS EC2 to prevent it from changing upon reboot.

Configure the following DNS records:

| Record Type | Host / Name | Target / Value | Purpose |
| :--- | :--- | :--- | :--- |
| **A** | `@` (or `nisolai.com`) | `76.76.21.21` | Points apex domain to Vercel Edge Network |
| **CNAME** | `www` | `cname.vercel-dns.com` | Points `www` subdomain to Vercel |
| **A** | `app` | `13.207.146.34` | Points platform/portal subdomain to AWS VM |

*(Optional: If routing TryPost or WAHA via subdomains, add CNAME or A records for `social` or `waha` pointing to `13.207.146.34`)*

## Part 2: Deploy Frontend Marketing on Vercel

1. Push your latest Git repository commits to GitHub/GitLab.
2. In the **Vercel Dashboard**:
   - Click **Add New** → **Project** → Select the `Anti-Gravity-Code` repository.
   - Framework Preset: **Next.js** (Root Directory: `./`).
   - Assign Domains: `nisolai.com` and `www.nisolai.com`.
3. Add the following **Environment Variables** in Vercel:
   ```env
   # Mandatory: Tells client & middleware where the authenticated app lives
   NEXT_PUBLIC_APP_URL="https://app.nisolai.com"

   # Recommended: Ensures lead forms (/contact, /partner, /grants) can deliver emails from Vercel
   RESEND_API_KEY="re_your_resend_api_key"
   EMAIL_FROM="Nisol AI <grants@nisolai.com>"
   TO_EMAIL="contact@nisolai.com"
   ```
4. Click **Deploy**.

> **Note on Routing**: The custom Next.js middleware automatically detects visits to `nisolai.com/login` or `nisolai.com/dashboard` and smoothly redirects visitors to `https://app.nisolai.com/...`.

## Part 3: Deploy Backend & App on AWS VM (`13.207.146.34`)

### 1. AWS Security Group Rules
Ensure your EC2 Security Group permits incoming traffic on:
- **Port 22** (SSH): Restricted to your IP
- **Port 80** (HTTP): Public (`0.0.0.0/0`) — Required for Caddy ACME/Let's Encrypt challenge & HTTP->HTTPS redirect
- **Port 443** (HTTPS): Public (`0.0.0.0/0`) — Required for secure application traffic
- *(Port 9000 Portainer / Port 8888 Dozzle: Keep restricted to your personal IP for security)*

### 2. Connect to the VM
```bash
ssh -i your-key.pem ubuntu@13.207.146.34
```

### 3. Pull Latest Code & Verify Required Files
```bash
cd /path/to/Anti-Gravity-Code
git pull origin main
chmod +x init-multiple-dbs.sh
```

### 4. Configure Production `.env`
Verify `/path/to/Anti-Gravity-Code/.env` contains all required service credentials:

```env
# Database Configuration
POSTGRES_DB=conductos
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_secure_postgres_password
POSTGRES_MULTIPLE_DATABASES=conductos,nisolai,trypost

# Redis Configuration
REDIS_PASSWORD=your_secure_redis_password

# Authentication (Better Auth)
BETTER_AUTH_SECRET=your_minimum_32_character_random_secret
BETTER_AUTH_URL=https://app.nisolai.com
NEXT_PUBLIC_APP_URL=https://app.nisolai.com

# Email Delivery (Resend)
RESEND_API_KEY=re_your_resend_api_key
EMAIL_FROM=Nisol AI <grants@nisolai.com>
TO_EMAIL=contact@nisolai.com

# LLM Providers (Required for Report Generation & AI Modules)
Gemini_NisolLabs_API_Key=your_gemini_api_key
OpenAI_NisolLabs_API_Key=your_openai_api_key
Claude_NisolLab_API_Key=your_claude_api_key

# Ancillary Services (TryPost & WAHA)
TRYPOST_APP_KEY=base64:your_generated_app_key
TRYPOST_APP_URL=https://app.nisolai.com
TRYPOST_REVERB_SECRET=your_reverb_secret
WAHA_USER=admin
WAHA_PASSWORD=your_secure_waha_password
```

### 5. Build and Launch Container Stack
```bash
docker compose up -d --build
```

### 6. Verify Running Containers
```bash
docker compose ps
```
You should see all containers in an `Up` or `healthy` state:
- `nisol-caddy`
- `nisol-postgres` (healthy)
- `nisol-redis` (healthy)
- `nisol-app`

To check live Caddy logs for SSL certificate issuance:
```bash
docker compose logs -f caddy
```

## Part 4: Verification & Smoke Testing Checklist

1. **Apex & Marketing Performance**:
   - Open `https://nisolai.com` and `https://www.nisolai.com`.
   - Verify that pages are delivered through Vercel Edge network with valid SSL.
2. **Seamless Navigation to App**:
   - In the navbar, click **Log In** or **Client Portal Log In**.
   - Verify it navigates to `https://app.nisolai.com/login`.
3. **App Domain Behavior**:
   - Opening `https://app.nisolai.com/` directly should automatically redirect unauthenticated users to `/login`.
4. **Authentication & Session**:
   - Log in with valid credentials.
   - Verify authentication succeeds against the PostgreSQL database on the AWS VM and redirects to `https://app.nisolai.com/dashboard`.
5. **Lead Capture & Notifications**:
   - Submit a test inquiry on `https://nisolai.com/contact` and verify email arrival via Resend.
